# SureVax CMS — Workflow Conformance Checklist

**Purpose:** Verify the revamped CMS covers every workflow from the AppSheet system. Each row = one behavior the old system has. Migration team marks the _Status_ column:

- ✅ **Match** — new CMS has equivalent behavior
- ⚠️ **Different** — new CMS handles it differently; note how in Δ column
- ❌ **Missing** — new CMS does NOT cover this; needs implementation or explicit decision to drop
- 🗑️ **Drop** — intentionally not migrating (deprecated or out of scope)

**Use:** Fill the Status + Δ columns as you verify. Hand the completed file back to the audit owner.
