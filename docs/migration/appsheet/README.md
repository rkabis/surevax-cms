## Status

- **Production cutover remains blocked.** The exact remaining work is indexed
  in [`WHAT-REMAINS-BEFORE-CUTOVER.md`](WHAT-REMAINS-BEFORE-CUTOVER.md).
- **Trials V/W completed a restart-safe full disposable local migration.** The
  final state includes 15,736 patients, 56,078 encounters, 12,684 rabies
  courses, 71,417 clinical orders, 41,332 transaction headers, 51,706 exact
  invoice lines and 41,786 payment legs.
- **The same frozen pack reruns cleanly.** Durable target links prevented every
  additional domain insert after both a real staged failure/resume and a full
  completed rerun.
- **Financial truth reconciles at both admitted grains.** Payment legs equal
  transaction `amount_paid` at PHP 56,368,563.20. The 39,113 transactions with
  admitted invoice detail reconcile exactly to PHP 51,387,000.00 gross;
  uncertain item sets remain withheld.
- **Vaccine histories and schedules are rebuilt locally.** The canonical
  clinical plan includes observed administrations, approved unknown-date
  external dose 1, safe scheduled slots and the guarded Day-31 `Missed` rule.
  Interior administrations are never invented from sequence alone.
- **Follow-up evidence can reduce the residual queue.** Five strict
  tracker-backed dose-2 events and six clean existing-event label repairs are
  identified; they must be recomputed/deduplicated against the final frozen
  pack and recorded as provenance-bearing dispositions.
- **Reference prerequisites now exist:** PayMongo and Other payment methods,
  Avega, Ayala Malls, and the three migration-owned tag definitions. Go-live
  service prices, staff access and opening state still require approval.

## Headline findings

1. **No new domain tables are needed for ordinary AppSheet concepts.** A separate 11-table `migration` control schema is required for immutable snapshots, reconciliation events, approvals, target idempotency links, sync checkpoints and the manual queue.
2. **Patient ID format flipped** Apr→May 2025 (UNIQUEID → initials+rownum), non-retroactively; legacy patient ID is dropped (A3).
3. **Transaction headers and tender legs are the financial authority.** Trials
   V/W loaded 41,332 headers and 41,786 payments; the payment total exactly
   matched imported `amount_paid`.
4. **Invoice detail is admitted only when source-linked services exactly equal
   the transaction gross.** The transaction-constrained projector loaded
   51,706 exact lines and withheld 1,788 mismatching transaction item sets.
5. **8 discount codes, one is a +15% markup** (AyalaMalls) — must not be treated as a discount.
6. **Dose number lives in `i_Label`**, not `i_DosageCount` (importer bug to fix).
7. **ARV course reconstruction is locally load-proven, not production-approved.**
   Trials V/W loaded 12,684 canonical courses and 71,417 orders while retaining
   explicit exception classes and provenance.
